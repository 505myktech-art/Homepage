# Display artwork sources

The outlined display-lettering SVG files in this directory are generated from:

- Cormorant — SIL Open Font License 1.1
- Noto Sans Traditional Chinese — SIL Open Font License 1.1

Font source: `google/fonts` on GitHub. The deployed SVG files contain paths rather than embedded font files, so their appearance does not depend on fonts installed on the visitor's device.

Regenerate from the project root with:

```powershell
npm.cmd run generate:display-art
```
