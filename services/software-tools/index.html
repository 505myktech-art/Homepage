    資料整理、查找或固定操作長期仰賴人工重複執行。

  2. 02

    現有工具不合流程

    大型系統功能很多，但真正需要的操作仍不順手。

  3. 03

    概念需要能操作

  4. 04

    內容需要長期維護

    網站或工具需要清楚結構，避免每次更新都必須重做版面。
